:: Settings backup rules: ::CONFIG app-id|Display name|Root|Relative path|Processes to close (optional)
:: Roots: APPDATA, LOCALAPPDATA, USERPROFILE, DOCUMENTS, HKCU. A path can be a folder, a single file or (HKCU) a registry key.
:: Display name must start like the app's name in Settings > Apps > Installed apps, or restore will say it isn't installed.
:: Processes (comma-separated, no .exe): an app that's still running is skipped rather than backed up mid-write.
:: Use one line per path with the same app-id. Change CONFIG to NOCONFIG to disable a rule.
